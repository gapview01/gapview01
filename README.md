## What I built in this break

Two small, public examples of the control pattern I care about:

- **[governed-agent-demo](https://github.com/gapview01/governed-agent-demo)**
  — plan → policy check → simulate → human approval → audit trail,
  including a cost limit.
- **[mcp-policy-gateway](https://github.com/gapview01/mcp-policy-gateway)**
  — an MCP server that puts those same guardrails around everyday
  commercial tools (customer comms, spend, account updates).

A longer personal build project sits alongside this, kept private.
The public work is the evidence of the approach.
